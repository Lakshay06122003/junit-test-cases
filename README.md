# JUnit Test Refactoring Project

This repository contains coursework-based Java projects where the core implementation was provided, and the focus was on building comprehensive JUnit test cases, improving code quality, and refactoring toward cleaner design.

## Overview

The project demonstrates how to validate existing code through testing and how to improve maintainability without changing the intended behavior. It includes multiple classes with corresponding test files, along with refactoring work guided by SOLID principles.

## What Was Done

- Wrote JUnit test cases for the provided classes.
- Refactored code where needed to improve readability and maintainability.
- Applied SOLID principles to reduce coupling and improve structure.
- Verified expected behavior across multiple scenarios and edge cases.

## Repository Structure

- `*.java` — implementation classes.
- `*Test.java` — JUnit test suites for the corresponding classes.
- `README.md` — project overview and notes.

## Skills Demonstrated

- Unit testing with JUnit.
- Test-driven thinking and behavior validation.
- Refactoring legacy or prewritten code.
- Object-oriented design and SOLID principles.
- Code organization and maintainability.

## Notes

This project started as coursework, but the emphasis here is on the testing and refactoring work rather than on building the original application logic from scratch.

## How to Run

1. Open the project in your Java IDE.
2. Make sure JUnit is configured in the project dependencies.
3. Run the `*Test.java` files to execute the test suites.
